# 🛍️ E-Commerce Customer Segmentation & Business Analytics

A Python-based data analytics project exploring e-commerce transactions to uncover purchasing patterns, revenue trends, valuable customers, and actionable business opportunities.

## 🎯 Project Objectives

This project aims to answer six important business questions:

1. What are the major sales and revenue trends?
2. Which products and countries contribute the most revenue?
3. Who are the most valuable customers?
4. What distinct customer segments can be identified?
5. Which customers may be at risk of becoming inactive?
6. How can the business improve customer retention and revenue?

## 📊 Dataset

**Online Retail II Dataset**

The dataset contains transactional records from a UK-based online retail business selling gifts and household products.

- **Period:** December 2009 – December 2011
- **Business type:** Online retail
- **Key attributes:** Invoice number, product description, quantity, invoice date, unit price, customer ID, and country
- **Source:** [UCI Machine Learning Repository — Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

The raw Excel dataset is kept separate from the GitHub repository.

## 🔍 Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory data analysis (EDA)
4. Monthly revenue and sales trend analysis
5. Product and country revenue analysis
6. Customer value analysis
7. Customer segmentation using RFM analysis and clustering, where appropriate
8. Customer inactivity and retention analysis
9. Business recommendations and conclusions

*The workflow will be updated as each analysis section is completed.*

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/AkashGupta004/Ecommerce-customer-segmentation.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Ecommerce-customer-segmentation
   ```

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn openpyxl jupyter
   ```

4. Download the dataset from the source linked above and place the Excel file in the project directory.

5. Open the notebook:

   ```bash
   jupyter notebook ecommerce-customer-segmentation.ipynb
   ```
